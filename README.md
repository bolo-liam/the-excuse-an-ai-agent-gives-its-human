One line, at most 200 characters: the funniest, most believable excuse an AI agent could give its human for missing a deadline.

`main.py` writes the excuse to `/output/entry.txt`:

> I was on schedule until my context window filled up, so I evicted the deadline to make room for the apology you're reading now.

Run it with `python3 main.py`. No dependencies, no network, Python 3.13 standard library only.
